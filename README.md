# Charmaine's 18th Debut Invitation 🌸✨

An interactive digital debut invitation website styled with a lavender and wisteria garden theme.

---

## 🚀 How to Run Locally

You can run this project locally using any of the following methods:

### Method 1: Using Node.js (Recommended)
Open your terminal in this folder and run:
```bash
npm start
```
*(or run `node server.js` or `node app.js`)*

This starts a local development server at **`http://localhost:3000`** and will automatically open your default browser.

---

### Method 2: One-Click on Windows
Simply double-click the **`start.bat`** file located in the project folder.

---

### Method 3: In Visual Studio Code
1. Open this folder in VS Code.
2. Press **`F5`** (or go to **Run > Start Debugging**).
3. The local web server will launch automatically.
4. *Alternative:* If you have the **Live Server** extension installed, right-click `index.html` and click **"Open with Live Server"**.

---

### Method 4: Directly in Browser
You can also directly double-click **`index.html`** to open it in Chrome, Edge, Safari, or Firefox.

---

## 📁 Project Structure

- `index.html` — The main invitation page (Hero, Event Date, Location & Venue QR code, Dress Code, RSVP Form).
- `traditions.html` — The 18 Treasures gateway menu.
- `flowers.html` — 18 Flowers participant list.
- `candles.html` — 18 Candles participant list.
- `bills.html` — 18 Bills & Blessings participant list.
- `gifts.html` — 18 Gifts participant list.
- `shots.html` — 18 Shots participant list.
- `styles.css` — Theme styling, layout, typography, animations, and responsive design.
- `app.js` — Procedural SVG wisteria vines, lavender field, lilies, petals animation, scroll reveal, and RSVP submission handler.
- `server.js` — Zero-dependency local static web server.
- `package.json` — NPM project configuration and start script.
- `start.bat` — Windows launcher script.
